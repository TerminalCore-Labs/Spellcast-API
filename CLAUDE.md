# Project Guidelines & Safety Rules

## Strict Security & Privacy
- NEVER inspect, read, display, cat, grep, or parse any `.env` file or variants (`.env.local`, `.env.production`, etc.).
- NEVER read or output files containing credentials, tokens, or private secrets.
- If environment variable definitions or schemas are needed, refer ONLY to `.env.example`.
- Do not suggest commands that print environment secrets into stdout or logs.
